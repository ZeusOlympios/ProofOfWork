# Prototype Status

This directory currently documents the proposed prototype; it is not a working application.

## Intended screens

1. Graduate project submission form.
2. Reviewer assessment workspace.
3. Anonymised employer candidate profile.
4. Shortlist action and decision rationale.

## Demonstration requirements

The future prototype should use clearly labelled synthetic candidates and scores. The interface should show the rubric, supporting evidence, missing evidence and assessment limitations.

## Not implemented

- Frontend application.
- Backend API.
- Database.
- Authentication and authorisation.
- GitHub repository verification.
- Practical task execution.
- Automated tests or deployment.

Do not present screenshots or sample data as evidence of a deployed or validated product.
