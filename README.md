# ProofOfWork
### Verified skills. Visible potential.

**Challenge:** Credify System Thinking Challenge 2026  
**Track:** Graduate Employability  
**Status:** Documentation-first concept and prototype plan. A working application has not yet been implemented.

## The problem

Graduates may develop useful technical skills through personal and academic projects but struggle to obtain interviews without formal work experience. Employers, meanwhile, have limited time to independently assess every applicant's actual ability.

This creates a reinforcing cycle: limited experience reduces access to interviews, fewer interviews reduce opportunities to gain experience, and the experience gap persists.

## Proposed solution

ProofOfWork proposes a structured assessment process that combines a graduate's project repository with a short practical task. Reviewers score observable evidence against a published rubric. Employers can initially compare pseudonymous candidate profiles before shortlisting.

## The prototype workflow

1. Graduate submits a repository URL, project description and technology information.
2. Reviewer evaluates code quality, problem-solving, testing and documentation.
3. Reviewer records scores, evidence and practical-task results.
4. Employer reviews pseudonymous profiles and supporting evidence.
5. Identity is disclosed only at the authorised shortlisting stage.

## Why this intervention?

We considered project-based assessment and employer-sponsored micro-internships. Project-based assessment was selected because it can reuse existing project work and standardise reviewer effort. Micro-internships may provide stronger workplace evidence but require more employer supervision.

## Proposed technology

- Frontend: React
- Backend: ASP.NET Core Web API using C#
- Database: PostgreSQL
- Version control: Git and GitHub

These are proposed technologies, not a claim that a functioning application has been built.

## Current limitations

This submission documents the proposed system and prototype design. It does not yet contain a functioning assessment application, integrated authentication, repository verification, automated scoring, or real candidate data. No hiring-impact or fairness claims have been empirically established.

## How to evaluate the proposal

Review the problem framing, intervention comparison, rubric, risk analysis and validation plan. A future implementation should be tested with synthetic data first, followed by a small, consent-based pilot with independent reviewers.

## Responsible use of AI

Any AI assistance used during development should be disclosed accurately. Scores should not be represented as verified until the stated assessment and verification procedures have actually been performed.
