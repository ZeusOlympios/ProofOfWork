# Validation Plan

## Status

Proposed tests only. No user research, reviewer study, or hiring-outcome evaluation has been completed as part of this documentation-first submission.

## Test 1: Rubric clarity

Ask two independent reviewers to score the same three sample projects. Compare category ratings and discuss differences.

Measure: exact agreement and average absolute score difference.

Possible decision rule for a pilot: revise criteria where reviewers frequently disagree by more than one rating point. This is a proposed rule, not a result.

## Test 2: Evidence traceability

For each assigned score, ask whether the reviewer can identify a concrete file, test, behaviour or observation supporting it.

Measure: percentage of category scores with specific supporting evidence.

## Test 3: Workflow usability

Give a small number of consenting test users a submission and review walkthrough.

Measure: completion rate, time taken, misunderstood fields and reported friction.

## Test 4: Anonymisation check

Inspect the employer-facing response and interface to ensure candidate names, email addresses and unnecessary identifiers are not exposed before shortlisting. Check metadata and free-text fields for accidental identity disclosure.

Measure: number of unnecessary identifying fields exposed.

## Test 5: Fairness and usefulness

In a later pilot, compare structured assessments with existing screening decisions. Examine whether the new process surfaces capable candidates previously overlooked. Use appropriate consent, privacy protections and sufficiently large samples before drawing conclusions.

Do not infer that anonymity alone eliminates bias.

## Key risks

- Copied or AI-generated work misrepresented as independently authored.
- Inconsistent reviewer interpretation.
- Unequal access to equipment, mentoring and internet.
- Candidate privacy breaches.
- Employers over-relying on a numeric score.
- Small samples creating misleading conclusions.

## Evidence discipline

Report planned tests as planned, not completed. Use synthetic records for demonstrations and label them clearly. Any later pilot should document participant consent, methodology, sample size and limitations.
